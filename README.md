# HORIZON CITY

> リアルを追求するFiveMロールプレイサーバー

---

## 概要

**HORIZON CITY** は、リアル志向のロールプレイ体験を提供する日本語FiveMサーバーです。

本サーバーは、現実世界に近い経済システム、職業体験、社会システムを実装し、没入感の高いロールプレイ環境を構築しています。すべてのプレイヤーに平等な機会を提供し、公平で透明性のある運営を心がけています。

個人運営でありながら、長期的な運営を前提とした設計を行い、プレイヤーが安心して参加できる環境を維持します。

---

## 特徴

### リアル志向のロールプレイ

- 現実世界に即した経済システムと職業体験
- 没入感を重視したロールプレイ環境
- メタ行為・パワープレイの禁止

### 公平で透明性のある運営

- 全プレイヤーに平等な機会を提供
- 特定ユーザーへの優遇措置は一切なし
- 明確なルールに基づいた公正な判断

### 明確なルール設計

- 誰にでも理解しやすいサーバールール
- ルール違反への一貫した対応
- 定期的なルール見直しとコミュニティへの反映

### 安定した運営方針

- 一時的な盛り上がりではなく長期運営を前提
- 計画的なアップデートとメンテナンス
- プレイヤーが安心して参加できる環境維持

**公式サイト:** `https://horizon-city.example.com` （仮）

### サーバーへの参加方法

1. **公式Discordサーバーへ参加**
   - 招待リンク: `discord.gg/horizoncity` （仮）
   - サーバー参加前に必ず利用規約・サーバールールをご確認ください

2. **サーバールールの確認**
   - [サーバールール](rules.html) を熟読してください
   - ルール違反は処罰の対象となります

3. **接続情報の確認**
   - Discord内の案内に従ってサーバーに接続してください

### 注意事項

- FiveMクライアントのインストールが必要です
- GTA Vの正規版（Steam / Epic Games 等）が必要です
- 安定したインターネット接続環境を推奨します
- 13歳未満の方の利用は推奨しません（保護者の同意が必要）
